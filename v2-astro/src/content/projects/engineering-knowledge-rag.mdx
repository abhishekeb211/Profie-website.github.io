## Context & Problem
Standard naive vector retrieval often fails on complex engineering manuals and technical schematics because keyword exactness (part numbers, error codes) is diluted by semantic embeddings. Furthermore, enterprise engineering manuals contain proprietary schematics that cannot leave the local workstation.

## Deterministic 6-Stage Pipeline
1. **Snapshot:** Immutable filesystem snapshotting of candidate document trees.
2. **RAM-Bounded Ingestion:** Monitors available OS memory dynamically to throttle PDF chunking:
```
\text{MaxBatchSize} = \left\lfloor \frac{0.80 \times \text{RAM}_{available}}{\text{AverageDocumentSize}} \right\rfloor
```
   preventing out-of-memory crashes on developer workstations.
3. **Lexical Indexing:** Fast FTS5 inverted indexing with BM25 ranking and prefix matching.
4. **Atomic Pointer Swapping:** Swaps in-memory index pointers atomically, eliminating dirty reads during live indexing.
