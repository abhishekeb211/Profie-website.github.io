## Executive Context & Systems Purpose
Unconstrained coding agents running loose in developer repositories can accidentally delete files, corrupt git trees, and burn through expensive frontier LLM tokens on trivial syntax formatting. **Supper-IDE** is an autonomous pair-programming orchestration platform designed around the **Anti-Gravity Adaptive Workspace (AMAWS v6.0)** specification, enforcing formal state-machine boundaries on every agent action.

## The 7-Step Sovereign Flow

```
1. Intake (Contract Parse & Goal Enforcement)
        │
        ▼
2. Model (Smart Cost Router: Complexity Score C(task))
        │
        ▼
3. Select (Least-Privilege Tool Descriptors via MCP)
        │
        ▼
4. Execute (Bounded Tool Invocation)
        │
        ▼
5. Checkpoint (Pre-Mutation Instantaneous Git Commit)
        │
        ▼
6. Verify (Pytest / AST / Linting Validation)
        ├── [Fails Tests] ──► Revert Checkpoint & Retry Step 4
        └── [Passes Tests]
                │
                ▼
7. Persist (Global Brain Cross-Session Memory Update)
```

## Economic & Architectural Advantages

1. **Intelligent Model Routing:** Supper-IDE computes a semantic complexity metric `mathcal(C)(task)`:
```
\text{Model} = \begin{cases} \text{Local Ollama / Gemini Flash (Low Cost)}, & \text{if } \mathcal{C}(task) < \theta_{simple} \\ \text{Claude 3.5 Sonnet / GPT-4o (High Reasoning)}, & \text{if } \mathcal{C}(task) \ge \theta_{simple} \end{cases}
```
   Routing over 80% of routine developer tasks to low-cost models, slashing operational AI API costs by over 80%.
2. **Pre-Mutation Rollback Guarantee:** Because every mutating filesystem tool invocation is preceded by a git commit snapshot, hallucinated refactorings or file deletions can be reversed with zero human panic.
3. **Cross-Session Global Brain:** A persistent knowledge substrate retains architectural conventions, user preferences, and project history across multiple developer sessions.
