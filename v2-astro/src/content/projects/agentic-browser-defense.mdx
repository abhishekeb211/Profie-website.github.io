## Executive Context & Research Significance
Autonomous web agents and Model Context Protocol (MCP) toolkits frequently succumb to indirect prompt injections, SSRF attacks, and rogue tool execution when parsing untrusted web pages. Standard sandboxes either grant excessive privileges or break agent workflows. The **Agentic Browser Defense System** establishes a formal cryptographic mediation architecture between the reasoning LLM and the execution environment.

## Host-Side Mediation Proxy Architecture

```
Autonomous Browser Agent (LLM)
       │
       ▼ [Tool Call Invocation]
┌──────────────────────────────────────────────┐
│ Host-Side Mediation Proxy Engine             │
│  ├── L2/L3 State Machine (Default: L2 Read)  │
│  ├── Capability Token Engine (8-Tuple HMAC)  │
│  ├── Parameter Lattice Containment Engine    │
│  ├── Monotonic Nonce High-Water Mark         │
│  └── Forward-Secure Ratcheted Paradata Ledger│
└──────┬───────────────────────────────────────┘
       │
       ├─► [Mutating Call in L2] ──► 100% Blocked & Denied
       │
       └─► [Valid Token + Lattice Pass] ──► Elevate to L3 ──► Execute Tool ──► Instant Demotion to L2
```

## Mathematical & Cryptographic Formulations

1. **8-Tuple Cryptographic Capability Token:**
```
\mathcal{T} = \langle \text{token\_id}, \text{orchestrator}, \text{delegatee}, \text{dest\_server}, \text{tool\_name}, \mathcal{L}_{param}, t_{exp}, \nu \rangle
```
   signed via `(HMAC-SHA256)(K_(secret), (canonical)(mathcal(T)))`.
2. **Parameter Lattice Subsumption:** An invocation with arguments `P_(call)` is admitted if and only if:
```
P_{call} \sqsubseteq \mathcal{L}_{param}
```
   For filesystem interactions, this enforces strict directory containment: `(Path)(P_(call)) subseteq (AllowedPrefixes)(mathcal(L)_(param))`. Out-of-bounds traversal (e.g. `../../etc/passwd`) is mathematically rejected.
3. **Forward-Secure Paradata Ledger Ratchet:** Each tool transaction `i` irreversibly links into a hash chain:
```
H_i = \text{SHA256}(H_{i-1} \parallel T_i \parallel \text{timestamp} \parallel P_{call} \parallel \text{result})
```
   Preventing an attacker who gains subsequent root privileges from rewriting past audit history.
