## Context & Problem
Modern browser agents require sending full-page screenshots or raw HTML DOM trees to external LLM providers, exposing passwords, financial numbers, and personal identifiers. Sanjaya.ai is engineered with a strict client-side privacy boundary.

## Technical Design
1. **Accessibility Tree Extraction:** Replaces bloated DOM trees with semantic accessibility nodes (role, label, state), cutting token payloads by 85%.
2. **Local PII Redaction Filter:** In-browser regex and named entity filters redact emails, phone numbers, and session cookies before context compilation.
3. **Bounded Action Model:** The agent cannot trigger payment buttons or account deletion without explicit cryptographic user confirmation.

## Acceptance & Performance
- Verified zero credential leakage across automated web-banking and e-commerce mock environments.
- Average action step synthesis under 250ms when running against quantized edge models.
