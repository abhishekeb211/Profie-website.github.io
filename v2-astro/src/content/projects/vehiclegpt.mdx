## Context & Problem
Connected vehicles generate gigabytes of sensor readings per hour, but remote cloud analytics incur latency, cellular data costs, and disconnection risks in remote transit corridors. VehicleGPT brings diagnostic reasoning to the vehicle edge.

## Implementation Architecture
1. **High-Throughput CAN Ingestion:** Ring-buffered daemon capturing sensor telemetry at up to 1000Hz without packet drops.
2. **Streaming Anomaly Detection:** Statistical bounds filter normal operating envelopes; anomalies trigger localized deep inspection.
3. **Edge Conversational Diagnostics:** Driver questions (e.g. "What caused that braking vibration?") are resolved against buffered physical logs rather than speculation.

## Evidence & Hardware Testing
- Profiled on ARM-based SBCs (Jetson / Raspberry Pi 5 class hardware).
- Maintained stable sub-12W thermal envelope under continuous packet ingestion.
