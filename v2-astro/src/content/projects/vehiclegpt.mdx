## Context & Problem
Connected vehicles generate gigabytes of sensor readings per hour, but remote cloud analytics incur latency, cellular data costs, and disconnection risks in remote transit corridors. VehicleGPT brings diagnostic reasoning to the vehicle edge.

## Implementation Architecture: Dual-Plane Decoupling

To prevent fatal thermal throttling and packet drops when operating under a strict 12W power ceiling, VehicleGPT decouples high-throughput real-time telemetry from probabilistic LLM inference into two isolated planes:

### Plane 0: Deterministic Real-Time Ingestion & Filtering (C++)
- **Zero-Copy Ring Buffer:** Pinned to dedicated CPU core with `SCHED_FIFO` priority, sustaining 1000Hz CAN-bus packet ingestion without context-switch latency.
- **Statistical Outlier Gating:** Zero-allocation rolling Z-score and Mahalanobis distance filters discard over 99.7% of nominal sensor frames in sub-microsecond intervals.

### Plane 1: Asynchronous Cognitive Reasoning Core (Quantized GGUF)
- **On-Demand Anomaly Activation:** Quantized INT4 model execution is halted during normal operating bounds and awakened exclusively when state anomalies or driver queries occur.
- **Formal Verification Sandbox:** AST diagnostic suggestions and clearing actions pass deterministic safety constraints before dispatch.

## Evidence, Reproducibility & Staked Attestation
- **Hardware Profile:** Benchmark verified on ARM64 developer boards (Raspberry Pi 5 / Jetson Orin Nano).
- **Thermal & Power Envelope:** Sustained sub-12W power consumption across continuous 60-minute stress runs.
- **Reproducible Harness:** Open-source synthetic CAN-packet testbench with deterministic seed generators published in repository benchmarks.
