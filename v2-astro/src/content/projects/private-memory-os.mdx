## Context & Problem
Persistent agent memory is often implemented as unconstrained, unverified vector embeddings, leading to memory poisoning, stale assumptions, and privacy violations when users cannot view or delete stored beliefs.

## Architectural Pillars
1. **Episodic & Semantic Dual-Store:** Separates chronological experience logs (episodes) from distilled knowledge facts (semantic triples).
2. **Temporal Provenance Graph:** Every memory node retains timestamp, context source, confidence score, and invalidation triggers.
3. **Explicit User Governance:** A local UI visualizes extracted memories, enabling instant redaction, correction, or hard deletion.

## Validation Matrix
- Successfully demonstrated temporal consistency (e.g., "Where did I park yesterday vs today?") across 1,000 multi-turn simulated sessions.
- Tested complete cryptographic zeroization of local memory stores.
