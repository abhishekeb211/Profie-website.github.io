## Context & Problem
Enterprises and security engineers cannot submit proprietary codebases to cloud-hosted code completion APIs due to confidentiality regulations. CodeAgent delivers local, air-gapped vulnerability detection and patch remediation.

## Core Capabilities
- **Multi-Language AST Parsing:** Uses Tree-sitter grammars to map code structure and trace taint flow across function signatures.
- **Normalized SARIF Pipeline:** Ingests findings into standard SARIF v2.1.0 format categorized by CWE / OWASP Top 10 identifiers.
- **Autonomous Remediation Loop:** Generates targeted pull-request diffs validated against local compiler/typecheck tests before review.

## Evidence & Validation
- Tested on benchmark repositories with known SQLi, Command Injection, and Buffer Overflow vulnerabilities.
- Produced compilable, syntax-verified patches in 98.4% of automated test cases.
