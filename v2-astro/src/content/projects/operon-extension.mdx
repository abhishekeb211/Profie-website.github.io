## Executive Overview

**Operon-ext** is a dual-tier developer platform comprising an Open VSX-compliant TypeScript extension for VS Code / Cursor and a high-performance Python FastAPI backend service (`operon`). 

It automates code planning, multi-file atomic patching, visual diff review, and regression testing directly within the developer's primary coding environment.

## The Visual Diff Approval Contract

To eliminate developer anxiety over automated AI code assistants corrupting working repositories, Operon-ext enforces a **strict visual approval gate**:
1. All generated file changes are held in an in-memory staging area.
2. The extension summons VS Code's native `vscode.diff` API, rendering an interactive side-by-side color-coded comparison.
3. Disk files are modified only after an explicit click on the extension's "Approve & Commit" control.
4. If tests fail, the developer can request iterative auto-remediation with a single click.
