## Executive Overview

**VulRAG** is an offline-first, sovereign AI-powered software security scanner and Automated Program Repair (APR) platform. Engineered to eliminate confidential code leakage in high-security, defense, and proprietary enterprise settings, it executes 100% locally using Ollama-hosted foundation models (Qwen, Llama, Mistral) and heterogeneous static analysis engines.

Backed by a formal **PRISMA 2020 Systematic Literature Review** and academic publications, VulRAG automates static finding ingestion, false-positive deduplication, and syntax-verified patch generation.

## Core Innovations

### 1. Multi-Analyzer Consensus & Deduplication
Raw static analysis tools frequently produce contradictory or high-volume noise. VulRAG unifies findings across heterogeneous analyzers into a standardized schema:
```
\text{Finding} = \langle \text{tool\_id}, \text{CWE\_id}, \text{file\_path}, \text{line\_range}, \text{severity}, \text{raw\_payload} \rangle
```
Findings with intersecting AST spans are clustered and ranked by a local LLM prompt grounded in surrounding file context chunks, systematically suppressing false positives.

### 2. Closed-Loop Sovereign Auto-Repair
Unlike generic coding assistants that return conversational code snippets, VulRAG generates unified diff format (`.diff`) patches that pass automated Tree-sitter AST validation before presenting them to the developer.

### 3. Comprehensive Compliance Export
Exports auditable reports in multiple industry formats including **CycloneDX Software Bill of Materials (SBOM)**, SARIF v2.1.0, JSON, and executive PDF summaries.
