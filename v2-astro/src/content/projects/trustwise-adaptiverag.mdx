## Executive Context & Enterprise Challenge
Enterprises holding confidential patents, clinical research, or proprietary financial strategies cannot safely query public LLM RAG APIs. Adversarial prompt injection, data poisoning, and side-channel differential probing present catastrophic risks. TrustWise AdaptiveRag was engineered as an air-gapped, policy-governed R&D research intelligence platform.

## Tri-Isolated Data Plane Architecture

TrustWise enforces strict physical and cryptographic boundaries across three distinct data planes:

```
Research Query
      │
      ▼
┌──────────────┐
│ Query Router ├─────────────► Fast-Path Grep/BM25 (<15ms)
└──────┬───────┘

┌───────────────────────────────┐
```

## Algorithmic & Security Mechanics

1. **Reciprocal Rank Fusion (RRF):** Fuses rankings from sparse BM25 and high-dimensional vector embeddings:
```
RRF\_Score(d \in D) = \sum_{m \in M} \frac{1}{k + r_m(d)}
```
   where `k=60` dampens rank variance between keyword exact hits and semantic neighbors.
2. **Correlation Budget & Leakage Prevention:** `CorrelationBudget` tracks cumulative mutual information across outbound queries:
```
I(Q_{out}; D_{vault}) \le \epsilon_{budget}
```
   If a sequence of probe queries risks inferring confidential vault attributes, the orchestrator triggers an immediate early halt with `EarlyStopReason.CORRELATION_EXHAUSTED`.
3. **Temporal Contradiction Detection:** Constructs chronological document dependency graphs, explicitly flagging when recent organizational memos invalidate older operational guidelines.
