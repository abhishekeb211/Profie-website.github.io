## Executive Context & Systems Challenge
Modern enterprise backbones process gigabits of NetFlow and IPFIX telemetry per second. Monolithic deep neural networks cannot be executed on every flow without introducing buffer overflows and dropped packets. Conversely, simplistic tree-based models fail to detect stealthy multi-stage zero-day infiltrations and suffer from acute class imbalance (where malicious attacks constitute `<0.1%` of flows).

## Two-Stage Asymmetric Gating Pipeline

```
Raw NetFlow / IPFIX Flow Tensors
               │
               ▼ [Feature Normalizer & Imbalance Policy]
┌──────────────────────────────────────────────┐
│ Stage 1: Ultra-Fast Binary Anomaly Gate      │
│  ├── Lightweight XGBoost / Fast MLP          │
│  ├── Direct Low-Latency Pass (<10 µs)        │
│  └── Escalate Suspicious Flows               │
└──────────────────────┬───────────────────────┘
                       │ (Only <2% suspicious flows escalated)
                       ▼
┌──────────────────────────────────────────────┐
│ Stage 2: Deep Multi-Class Fingerprinting     │
│  ├── Tabular Flow Transformer (transformers) │
│  ├── Deep Latent Autoencoder (deep.py)       │
│  └── Cost-Sensitive Hierarchical Ensemble    │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
 Granular Attack Categorization (DDoS, PortScan, Botnet, Web Attack, Infiltration)
```

## Algorithmic & Latency Optimization

1. **Asymmetric Computational Gating:** Let `x` be an incoming flow vector. Stage 1 computes `P((Malicious) mid x)` using a pruned decision tree:
```
\text{Decision} = \begin{cases} \text{PASS (Benign)}, & \text{if } P(\text{Malicious} \mid x) < \tau_1 \\ \text{ESCALATE (Stage 2)}, & \text{if } P(\text{Malicious} \mid x) \ge \tau_1 \end{cases}
```
   Because `>98%` of enterprise production traffic is benign, Stage 1 clears the vast majority in `<10 u(s)`, reserving heavy Tabular Transformer attention `O(N^2 * d)` exclusively for the small fraction of ambiguous flows.
2. **Rare-Attack Smearing Mitigation:** Standard cross-entropy loss causes models to overlook rare categories like stealth Infiltration attacks (`<30` occurrences among 500,000 flows). The pipeline integrates cost-sensitive loss weighting with borderline synthetic sampling on train splits only, increasing minority attack recall from `<15%` to `>85%`.
